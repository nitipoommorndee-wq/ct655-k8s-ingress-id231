Web-Based IDE: แพลตฟอร์มเขียนโปรแกรม จำลองการทำงาน และอัปโหลดโค้ดลงบอร์ดไมโครคอนโทรลเลอร์ผ่านเว็บแอปพลิเคชัน
การเรียนเขียนโปรแกรมไมโครคอนโทรลเลอร์ในห้องเรียนมักติดปัญหาที่ไม่เกี่ยวกับเนื้อหา เช่น ต้องติดตั้ง Arduino IDE ติดตั้งไดรเวอร์ และตั้งค่าพอร์ต เครื่องของโรงเรียนหลายแห่งถูกจำกัดสิทธิ์การติดตั้งโปรแกรม หรือเป็น Chromebook และผู้เรียนแต่ละช่วงวัยก็ต้องการเครื่องมือคนละระดับ งานวิจัยนี้จึงพัฒนา The Charm Web-Based IDE ซึ่งเป็นเว็บแอปพลิเคชันที่ทำได้ครบทุกขั้นตอน คือ เขียนโปรแกรม คอมไพล์ จำลองการทำงาน และอัปโหลดโค้ดลงบอร์ด TCR Fusion Pro ที่ใช้ชิป ATmega328P และเข้ากันได้กับ Arduino Nano โดยไม่ต้องติดตั้งซอฟต์แวร์หรือไดรเวอร์เพิ่ม
ระบบประกอบด้วย 4 ส่วนหลัก ส่วนแรกคือตัวแก้ไขโค้ดแบบผสม 4 โหมดตามระดับผู้เรียน ได้แก่ Text สำหรับเขียนภาษา C/C++ บน CodeMirror, Flowchart สำหรับเขียนเป็นผังงานแบบมีโครงสร้าง, Blocks ที่ใช้ Google Blockly และ Icons ที่เป็นบล็อกรูปภาพสำหรับเด็กเล็ก โหมดเชิงภาพทุกโหมดสร้างโค้ด C++ ที่เรียกใช้ไลบรารีของบอร์ดให้อัตโนมัติ ผู้เรียนจึงเห็นโค้ดจริงตลอดเวลาและนำไปเขียนต่อในโหมด Text ได้ ส่วนที่สองคือบริการคอมไพล์บน Google Cloud Run ที่ตรวจความปลอดภัยของโค้ดก่อน แล้วคอมไพล์ด้วย arduino-cli และ avr-gcc ส่วนที่สามคือตัวจำลองที่นำไฟล์ .hex ที่คอมไพล์ได้มารันบนชิป ATmega328P เสมือนด้วยไลบรารี avr8js และแสดงบอร์ดเป็นภาพสามมิติ ส่วนที่สี่คือระบบอัปโหลดที่ส่งไฟล์ .hex เดียวกันลงบอร์ดจริงผ่าน Web Serial API ด้วยโปรโตคอล STK500 ที่พัฒนาขึ้นเอง นอกจากนี้ยังมีรหัสเข้าใช้รายห้องเรียนและหน้าสำหรับครูเพื่อใช้ในชั้นเรียน
จุดสำคัญของการออกแบบคือ ไฟล์ .hex ไฟล์เดียวกันถูกใช้ทั้งในตัวจำลองและการอัปโหลด ผลที่ผู้เรียนเห็นในตัวจำลองจึงมาจากโปรแกรมเดียวกับที่บอร์ดจริงทำงาน ผู้เรียนที่ยังไม่มีบอร์ดก็ฝึกเขียนและทดลองได้ และลดความเสี่ยงที่อุปกรณ์จะเสียหายจากการต่อวงจรผิด
ผลการทดสอบความเป็นไปได้เบื้องต้นพบว่า โปรแกรมทดสอบ 98 โปรแกรมที่สร้างจากทั้ง 4 โหมดคอมไพล์สำเร็จทั้งหมด ใช้เวลาเฉลี่ย 542 มิลลิวินาที ตัวจำลองให้คาบการกะพริบ 500 มิลลิวินาทีคลาดเคลื่อนไม่เกิน 0.11 มิลลิวินาที อ่านค่าแอนะล็อกได้ตรงกับค่าที่ป้อน และทำงานเร็วกว่าเวลาจริงประมาณ 4.2 เท่า ส่วนการตรวจความปลอดภัยปฏิเสธโค้ดต้องห้ามได้ครบทั้ง 7 รูปแบบ การทดสอบนี้วัดบนเครื่องของผู้วิจัย ยังไม่ได้วัดบน Cloud Run และยังไม่ได้วัดขั้นตอนอัปโหลดลงบอร์ด
ขั้นต่อไปของงานวิจัยคือทดสอบระบบบนคลาวด์และบนบอร์ดจริง รวมถึงนำไปทดลองใช้กับผู้เรียนในชั้นเรียน เพื่อประเมินว่าเครื่องมือนี้ช่วยให้ผู้เริ่มต้นเรียนเขียนโปรแกรมไมโครคอนโทรลเลอร์ได้ง่ายขึ้นเพียงใด
